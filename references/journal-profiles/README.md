# Journal profile mechanism (no fixed, assumed policies)

Potential targets include OMEGA, IJPE, JRCS and ECR. Profiles must record: official publisher URL, author-guidelines retrieval date, submission format and current anonymity requirements, reference style, data and supplementary material policies and scope fit. Refresh from official guidance before every real submission; do not invent rankings/quartiles or static journal policies. Offline G6 only checks mathematical, source and citation integrity; journal-specific compliance requires a separate verified profile and human approval.
