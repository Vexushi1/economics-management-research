# Phase 8 — G6 final submission gate

Run `audit_submission` with independent, trusted PDF source, anchor, ModelSpec, exact parameter snapshot, Phase 5 proof ledger, cited-claim audit records and peripheral prose. Never trust the submitted `.tex` digest or a claimed status embedded in draft metadata. Recompute all bindings and compare exact canonical TeX and trusted macro payload. Any `UPSTREAM_STALE`, `TRUSTED_MACRO_TAMPERED`, `UNPROVEN_PROPOSITION`, `CLAIM_UNSUPPORTED`, `DOI_METADATA_NOT_VERIFIED` or unresolved PDF-to-model semantic bridge must BLOCK.

Outside the executable proof pipeline, independently review manuscript content and evidence semantics, anonymization, chart/table references, supplements, and the latest target journal author guide. No online journal rule is hardcoded as a universal requirement. G6 offline first version cannot authenticate a human reviewer, prevent manual edits after audit, or certify article truth; it deliberately blocks semantic bridges still `NOT_VERIFIED`. Do not claim submission-ready while any blocker exists.

Keep versioned artifacts; correcting upstream model versions makes downstream drafts stale. Prohibited: calling a proof sketch strict proof, dropping `\unproven{}`, replacing unsupported claims with fabricated sources, or silently modifying core macros.
